Componentes de Orquestación

Componente Rol de Orquestación Orquesta a Notebook
Orquestador LangChain / LangGraph — Coordina flujo completo Todos los componentes RAG1, RAG
Cadena de Seguridad Orquesta validaciones en secuencia: PII → Ético → Rate → Injection 4 filtros de seguridad RAG5
Motor RAG Orquesta: Splitter → Embeddings → FAISS → Recuperación de contexto Text Splitter, Embeddings, Vector Store RAG1
Motor de Razonamiento Orquesta: CoT → Zero/Few-Shot → LLM → Memoria conversacional GPT-4.1, Prompts, Memoria Chain_of_Thought, Notebook1
Observabilidad Orquesta: Trazas LangSmith → Logging → Métricas → Clasificación LangSmith, Logger, Recolector RAG3
Notificaciones Orquesta: Reportes HTML → Gmail SMTP → Entrega Generador HTML, SMTP RAG4
Agente Multi-Herramienta Orquesta: Function Calling → Diagnóstico/Stock/Servicio → Respuesta 3 herramientas especializadas 3-agent-vulcanizacion
